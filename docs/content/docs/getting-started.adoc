= Getting Started

DiabolicUI runs on one client only: *WotLK 3.3.5a* (`Interface: 30300`,
Lua 5.1). There's no build step: the game reads the files as they are.

== You need

|===
| Tool | For

| A 3.3.5a client | Trying changes in game (`/reload`)
| `lua5.1`, `luac5.1` | Tests and syntax checks
| `hugo`, `asciidoctor` (optional) | This site: `hugo server` from `docs/`
|===

== Load order

`DiabolicUI.toc` loads one XML file per folder, and each XML lists its
`.lua` files in order.

++++
{{< mermaid >}}
flowchart TD
    toc["📜 DiabolicUI.toc"] --> locale["🌐 locale"] --> engine["⚙️ engine"]
    engine --> data["📦 data"] --> handlers["🧰 handlers"] --> media["🎨 media"]
    media --> settings["📐 settings"] --> defaults["💾 defaults"] --> modules["🧩 modules"]
{{< /mermaid >}}
++++

|===
| Folder | Holds

| `locale/` | Translations (`+L["..."]+`), English first
| `engine/` | The framework (`engine-core.lua`) and 3.3.5 helpers
| `data/` | Colors, constants, shared functions
| `handlers/` | Shared building blocks: unit frames, buttons, orbs, bars, popups, `/dui`
| `media/` | Fonts, textures, sounds
| `settings/` | Fixed sizes, positions, textures (read-only)
| `defaults/` | The player's options and their defaults (saved)
| `modules/` | The features, one folder each (link:{{< relref "modules" >}}[map])
| `tests/` | The test suite, run outside the game
|===

== The work loop

++++
{{< mermaid >}}
flowchart LR
    edit["✏️ Edit"] --> check["🔎 luac5.1 -p file"] --> test["🧪 lua5.1 tests/test_x.lua"] --> game["🎮 /reload in game"]
    game -- "not right" --> edit
{{< /mermaid >}}
++++

[source,bash]
----
luac5.1 -p modules/chat/cleaner.lua     # syntax, in a second
lua5.1 tests/test_chat_cleaner.lua      # the tests for what you touched
tests/run_all.sh                        # everything, before a commit
----

Texture changes need a full client restart, not just `/reload`.

== Useful commands in game

|===
| Command | Does

| `/dui config` | The options panel
| `/dui move` | Unlock and move frames
| `/dui setscale <n>` | UI scale
| `/reload`, `/rl` | Reload the UI
|===
