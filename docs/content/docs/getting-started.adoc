= Getting Started

One client only: *WotLK 3.3.5a* (`Interface: 30300`, Lua 5.1). No build step: the game reads the
files as they are.

You need a 3.3.5a client and `lua5.1` with `luac5.1`. For this site, `hugo` and `asciidoctor`
(`hugo server` from `docs/`).

== The work loop

[source,bash]
----
luac5.1 -p modules/chat/cleaner.lua     # syntax, in a second
lua5.1 tests/test_chat_cleaner.lua      # the tests for what you touched
----

Then `/reload` in game. A texture or a new file needs a full restart.

== Folders

|===
| Folder | Holds

| `modules/` | The features, one folder each (link:{{< relref "modules" >}}[map])
| `windows/` | Where every window's parts go (link:{{< relref "windows-editor" >}}[editor])
| `settings/` | Fixed sizes, positions, textures, colours
| `defaults/` | The player's options
| `handlers/` | Shared pieces: unit frames, buttons, orbs, bars, popups, `/dui`
| `engine/`, `data/` | The framework, constants, helpers
| `locale/` | Translations
| `media/` | Fonts, textures, sounds
| `tools/`, `tests/` | The editor and its tool, the tests
|===

== In game

|===
| Command | Does

| `/dui config` | The options
| `/dui move` | Unlock and move frames
| `/dui layout` | Save the open windows for the editor
| `/rl` | Reload
|===
