= Rules

|===
| Rule | Checked by

| 3.3.5 API only, no version checks | `test_api_usage.lua`, `test_wotlk_globals.lua`
| Never add a missing API to `_G` or the frame metatable (other addons sniff those names) | Review
| Everything `local`; a global on purpose is `+_G.NAME = value+` | `test_no_global_leaks.lua`
| Every `.lua` is in an `.xml`, every entry exists | `test_addon_loads.lua`
| Every locale key exists and is used; a text 3.3.5 lacks becomes a key | `test_locales.lua`
| One anchor point, on one frame, plus an offset | Review
| A header comment on every new file | Review
| Say if something's only syntax- and test-checked, not seen in game | You
|===

== Later API, and 3.3.5's

|===
| Later clients | 3.3.5

| `+PlaySoundKitID(SOUNDKIT.X)+` | `PlaySound("igMainMenuOpen")`
| `texture:SetColorTexture(r, g, b, a)` | `texture:SetTexture(r, g, b, a)`
| `frame:SetShown(flag)` | `if flag then frame:Show() else frame:Hide() end`
| `IsInGroup()` | `+GetNumRaidMembers() > 0 or GetNumPartyMembers() > 0+`
| `GetNumGroupMembers()` | `GetNumRaidMembers()`
| `+GROUP_ROSTER_UPDATE+` | `+PARTY_MEMBERS_CHANGED+`, `+RAID_ROSTER_UPDATE+`
| `+PLAYER_ENTERED_VEHICLE+` | `+UNIT_ENTERED_VEHICLE+` with `unit == "player"`
| `UnitIsTapDenied(unit)` | `Engine.UnitIsTapDenied(unit)`
| `GameTooltip:IsForbidden()` | Nothing: never forbidden on 3.3.5
| `FriendsMicroButton`, `GuildMicroButton` | `SocialsMicroButton`
| `font:GetFont()`, `font:CopyFontObject(other)` on a `Font` | Nothing: one XML `<Font>` per size
|===

A missing event fails silently, and the fake client's `Font` objects are kinder than the real ones: a
passing test can still crash in game.

== Texture canvas

Our decorative textures have a canvas (`+texture_size+`) larger than their art (`size`). To size the
art, scale the whole canvas:

[source,lua]
----
local scale = wantedWidth / config.size[1]
texture:SetSize(config.texture_size[1] * scale, config.texture_size[2] * scale)
----
