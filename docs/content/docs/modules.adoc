= Modules Map

|===
| Folder | What's there | Good to know

| `actionbars/` | One module, one widget per file (`bar1.lua`, `pet.lua`, `xp.lua`...) | Buttons come from the `ActionButton` handler
| `unitframes/` | `units/` the frames, `elements/` what they show | Built by the `UnitFrame` handler
| `nameplates/` | `nameplates.lua`, `auras.lua` | 3.3.5 plates have no unit: one learns its GUID while it's the target or mouseover
| `blizzard/` | One file per Blizzard piece, named after it | Below
| `chat/` | `windows`, `bubbles`, `filters`, `cleaner`, `slide`, `copy` | Web links use our own `url` link type, so `filters.lua` overrides `SetItemRef`
| `objectives/` | Tracker, capture bars, world state, warnings | The tracker only changes alpha: its item buttons are secure
| `minimap/` | An Ace3 addon kept as it is | Its own namespace and `+DiabolicUI_Minimap_DB+`: don't merge it into `+DiabolicUI_DB+`
| `menu/` | `/dui config`: one `page-*.lua` per page, `controls.lua`, `movers.lua` |
|===

== The windows (`blizzard/`)

|===
| File | Does

| `windows.lua` and `windows-*.lua` | The kit: stone, iron, red band, title plate and foot; `-tabs`, `-controls`, `-buttons` and `-zones` hold those parts
| `panels.lua` | Every window listed in `panels` in `settings/blizzard.lua`
| `character.lua`, `mail.lua`, `auction.lua`... | A window that needs more than that line
| `adjust.lua` | Puts parts where `settings/positions.lua` says
| `layout-scan.lua` | `/dui layout`, for the link:{{< relref "windows-editor" >}}[editor]
| `lootframe.lua`, `rollwindow.lua`, `lootpreview.lua` | Loot (link:{{< relref "raid-rolls" >}}[Raid Rolls])
|===

The kit's calls, on `Engine:GetModule("Blizzard: Windows")`: `CreateWindow`, `CreateHeader`, `SetTitle`,
`AddFooter`, `HangTabs`, `StyleButtons`, `StyleDropDown`, `StyleEditBox`, `StyleCheckBox`,
`StyleScrollBars`, `AddPanel`, `AddZone`, `AddParchment`, `LineBand`.
