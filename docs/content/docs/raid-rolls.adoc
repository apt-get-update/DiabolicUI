= Raid Rolls

Two windows, off unless `rollWindow` is on (`/dui config` → AddOns). They read the master looter's
chat, whatever addon wrote it, so raiders need nothing else.

|===
| File | Shows

| `rollwindow.lua` | The item up for a roll, its time left, Main Spec, Off Spec and Pass, then your roll
| `lootpreview.lua` | The boss's loot still to roll, the item being rolled in gold
|===

++++
{{< mermaid >}}
flowchart LR
    ml["👑 Master looter"] -- "chat" --> check{"🔒 CanPutUpRolls"}
    check -- "Roll for [item] 20s" --> roll["🎲 Roll window"]
    check -- "Loot from Boss: ..." --> preview["📋 Loot preview"]
    corpse["💀 A corpse opened"] -- "addon message" --> preview
    roll -- "rolling, ended" --> preview
{{< /mermaid >}}
++++

`CanPutUpRolls` in `rollwindow.lua` says who's trusted: a raid warning or the leader always, raid and
party chat from the master looter or an assistant.

|===
| Message | Does

| A link and "roll" | Adds a row; "20s" sets its time
| A link and "wins", "awarded", "cancel"... | Removes its row
| "roll" and a number, no link | The last row's time
| `Loot from Boss: [a] [b]`, `Boss dropped 2 items:` | Fills the preview
|===

Anyone with DiabolicUI who opens a corpse under master loot also sends the items as addon messages
(prefix `DiabolicUI`).

*To try it:* `/dui config` → Units → *Fake Loot Roll*. Tests: `tests/test_session_rollwindow.lua`.
