= Modules & Widgets

== A module file

[source,lua]
----
-- What this file is for, in one or two lines.
local ADDON, Engine = ...
local Module = Engine:NewModule("Blizzard: LootFrame")
local L = Engine:GetLocale()

Module.OnInit = function(self)
	self.config = self:GetDB("Blizzard").loot   -- static: sizes, textures
	self.db = self:GetConfig("LootFrame")       -- saved: the player's options
end

Module.OnEnable = function(self)
	if (not self.db.enableSkin) then
		return
	end
	self:CreateWindow()
end
----

Then list the file in its folder's `.xml`.

== Widgets: one module, many files

A big module creates itself once; the other files add widgets to it.

[source,lua]
----
local Module = Engine:GetModule("ActionBars")
local Widget = Module:SetWidget("Bar: Floaters")

Widget.OnEnable = function(self)
	-- ...
end
----

== Stepping aside for another addon

[source,lua]
----
local Module = Engine:NewModule("ChatBubbles")
Module:SetIncompatible("NiceBubbles")
----

When that addon is loaded, the module's `OnInit` and `OnEnable` never run.

|===
| Module | Steps aside for

| `ChatWindows` | Prat-3.0
| `ChatBubbles` | NiceBubbles
| `ChatFilters` | gUI4_Chat
| `ChatCleaner` | ChatCleaner, CleanerChat
| `NamePlates` | Kui_Nameplates, TidyPlates (and its forks), NeatPlates, SimplePlates, gUI4_NamePlates
| `Blizzard: Containers` | Backpacker, BlizzardBagsPlus
| `Blizzard: Tooltips`, `Blizzard: ItemTooltips` | TipTac, TinyTip, TinyTooltip
| Boss and arena frames | Gladius, GladiusEx
|===
