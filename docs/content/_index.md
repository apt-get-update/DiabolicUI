# DiabolicUI Developer Documentation

DiabolicUI is a full UI replacement addon for the WotLK 3.3.5a client, built on a
small hand-rolled module framework ("the Engine") instead of Ace3 or oUF.

This site documents how the addon is put together for anyone working on the
code — module lifecycle, the handler/element pattern used by the unit frames,
config conventions, and the house rules that keep the codebase consistent.

Start with **[Getting Started]({{< relref "docs/getting-started" >}})**.
